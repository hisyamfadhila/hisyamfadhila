## 🧩 Featured Projects

### 🛩️ KRTI UAV Technology Development
Kontribusi pada tim mekanik Robotika UNY untuk pengembangan struktur UAV, pemilihan material, fabrikasi, assembly, dan integrasi sistem. Tim meraih **peringkat 4 KRTI 2024 Yogyakarta**.

### 🎵 Music Genre Classification with EfficientNetB2
Sistem klasifikasi genre musik berbasis CNN EfficientNetB2 dengan preprocessing MFCC, dataset 1.000+ audio, 10 genre, dan akurasi validasi 89%.

### ⚖️ Self-Balancing Robot with Fuzzy Logic & Kalman Filter
Robot self-balancing dengan Fuzzy Logic, PID, dan Kalman Filter untuk meningkatkan akurasi sensor IMU serta stabilitas sistem.

### ♻️ Automatic Waste Sorter with YOLO11n
Sistem pemilah sampah otomatis berbasis YOLO11n, ESP32, dan aktuator servo untuk deteksi objek real-time dan sorting fisik.

### 🤖 4-DOF Robot Arm with ROS2 & Computer Vision
Robot arm 4-DOF berbasis ROS2, OpenCV, YOLO, inverse kinematics, servo control, dan komunikasi antar-node.
